# Language Translator Tool 🌍

A simple and user-friendly Language Translator built using Python, Streamlit, and Deep Translator. The application automatically detects the input language and translates text into 100+ supported languages.

## Features

* 🌐 Translate text into 100+ languages
* 🔍 Automatic source language detection
* ⚡ Fast and easy-to-use interface
* 🎨 Built with Streamlit
* 🆓 No paid API key required

## Technologies Used

* Python
* Streamlit
* Deep Translator

## Installation

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Navigate to the project directory:

```bash
cd project-folder
```

3. Install the required dependencies:

```bash
pip install streamlit deep-translator
```

## Usage

Run the application using:

```bash
python -m streamlit run language_translationa_ai.py
```

The application will open automatically in your browser.

## How It Works

1. Enter the text you want to translate.
2. Select the target language from the dropdown menu.
3. Click the **Translate** button.
4. View the translated text instantly.
